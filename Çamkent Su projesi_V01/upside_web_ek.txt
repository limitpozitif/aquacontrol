UPSIDE WEB EKİ — KALDIRILDI / UDP'YE TAŞINDI
================================================================================
Bu dosya, HTTP /data (8081) ekinin ORİJİNAL referansıdır. v8'den itibaren
UPSIDE'da HTTP web sunucusu YOKTUR. UPSIDE'ın panel verisi, zaten var olan
ESP-to-ESP UDP broadcast paketiyle DOWNSIDE'a taşınır.

YAPILAN DEĞİŞİKLİK (upside_web_entegre.txt içinde):
1. #include <WebServer.h>, "WebServer web(8081)", "bool webStarted" → SİLİNDİ.
2. loop() içindeki web kayıt bloğu (web.on("/data") / web.begin() /
   web.handleClient()) → SİLİNDİ.
3. void webData() ve String webEscape() fonksiyonları → SİLİNDİ.
4. struct UdptxPacket GENİŞLETİLDİ (yalnızca yangın basıncı değil, panelin
   ihtiyacı olan TÜM veri taşınır) ve udpSend() tüm alanları doldurur:

struct UdptxPacket
{
  uint8_t deviceID;
  uint32_t counter;
  float siteTon;
  float siteCap;
  float sitePressure;
  bool  sitePumpOn;
  float sitePumpFreq;
  float sitePumpCur;
  uint16_t sitePumpVolt;
  bool  siteFault;
  float fireTon[4];
  float fireCap;
  float firePressure;
  bool  firePumpOn;
  float firePumpFreq;
  float firePumpCur;
  uint16_t firePumpVolt;
  bool  fireBigOn;
  bool  fireFault;
  bool  fillValveOn;
  float fireBigFreq;
  bool  siteStart;
  bool  fireStart;
  bool  fire1Start;
  bool  sysStopped;
  bool  sitePressureOK;   // Madde 1: site basınç sensörü sağlığı
  bool  firePressureOK;   // Madde 1: yangın basınç sensörü sağlığı
  uint16_t crc16;         // Madde 5: paket bütünlük CRC'si (son eleman!)
};

CRC (Madde 5): crc16 alanı struct'ın SON elemanıdır. Gönderen (upside) CRC'yi
offsetof(UdptxPacket,crc16) kadar olan baytlardan hesaplar; alıcı (downside)
aynı şekilde doğrular. CRC tutmayan paketler yok sayılır. Upside ayrıca
UdprxPacket'ine (downside→upside, reset isteği) crc16 son alanını eklemiştir;
downside'ın UdptxPacket'i ile birebir aynı olmalıdır.

KRİTİK KURAL: Bu struct'ın alan sırası ve tipleri, DOWNSIDE'daki UdprxPacket ile
BİREBİR AYNI olmalıdır. İki taraf da packed DEĞİL (aynı derleyici/hizalama).
Sıra veya tip değişirse paket boyutu eşleşmez ve iki taraf da paketi reddeder.

udpSend() alan kaynakları (upside içindeki mevcut değişkenler):
  siteTon      = tankLevels[1].tankTonaj
  siteCap      = calcTankVolumeTon(1, tanklar[1].yukseklik_mm)
  sitePressure = siteBasinc
  sitePump     = inverterState[6] (running / frequency/10 / current/10 / voltage)
  siteFault    = inverterState[6].status & 0x0008
  fireTon[i]   = tankLevels[2..5].tankTonaj
  fireCap      = calcTankVolumeTon(2, tanklar[2].yukseklik_mm)
  firePressure = yangin_basinc
  firePump     = inverterState[7]
  fireBigOn    = inverterState[8].running
  fireBigFreq  = inverterState[8].frequency / 10.0f
  fireFault    = inverterState[7].status & 0x0008
  fillValveOn  = oto_dolum
  siteStart    = site_start   (site pompası açık/kapalı)
  fireStart    = fire_start   (yangın pompası açık/kapalı)
  fire1Start   = fire1_start  (büyük yangın/fire1 pompası açık/kapalı)
  sysStopped   = stop_sys     (tüm sistem kapalı)
