================================================================================
ÇAMKENT AQUA — WEB PANEL /data SÖZLEŞMESİ
================================================================================
Bu dosya, web paneli (app_live.js) ile firmware arasındaki VERİ SÖZLEŞMESİDİR.
Yalnızca YENİ dosyalar bu şemaya uyar. Mevcut dosyalara dokunulmaz.

- DOWNSIDE web host'tur: /data ucu, kendi verisini üretir + UPSIDE'ın UDP
  broadcast paketinden (port 4210) gelen veriyi tek JSON'da birleştirir.
- UPSIDE'ta web/HTTP sunucusu YOKTUR (v8). Tüm UPSIDE verisi ESP-to-ESP UDP
  paketiyle DOWNSIDE'a taşınır; DOWNSIDE oradan site/fire/fillValve JSON'unu kurar.
- Tarayıcı yalnızca DOWNSIDE'ın /data'sını görür. Böylece panelin app.js'teki
  data objesiyle birebir uyumlu tek JSON oluşur.

2) ALAN EŞLEMESİ — UPSIDE (site/fire/fillValve kısmı)
================================================================================
Değerler UPSIDE'da üretilir, UDP paketiyle (UdptxPacket) DOWNSIDE'a gelir;
DOWNSIDE webData() bunları rxPacket'ten JSON'a yazar. Alan kaynakları:
JSON alanı            Kaynak (upside_web_entegre.txt)
--------------------  -------------------------------------------------------
site.water.ton        tankLevels[1].tankTonaj
site.water.cap        calcTankVolumeTon(1, tanklar[1].yukseklik_mm)  // tam dolu
site.pressure         siteBasinc
site.pump.on          inverterState[6].running
site.pump.freq        inverterState[6].frequency / 10.0f
site.pump.cur         inverterState[6].current  / 10.0f
site.pump.volt        inverterState[6].voltage
site.fault            (inverterState[6].status & 0x0008) != 0
site.pressureOK       siteSensorOK   (Madde 1: upside site sensörü sağlığı; 10sn/alt-eşik)

fire.tanks[i].ton     tankLevels[i+2].tankTonaj    (i = 0..3 → tank 2..5)
fire.tanks[i].cap     calcTankVolumeTon(i+2, tanklar[i+2].yukseklik_mm)
fire.pressure         yangin_basinc
fire.pump.on          inverterState[7].running
fire.pump.freq        inverterState[7].frequency / 10.0f
fire.pump.cur         inverterState[7].current  / 10.0f
fire.pump.volt        inverterState[7].voltage
fire.big.on           inverterState[8].running
fire.big.freq         inverterState[8].frequency / 10.0f
fire.fault            (inverterState[7].status & 0x0008) != 0
fire.pressureOK       fireSensorOK   (Madde 1: upside yangın sensörü sağlığı; 10sn/alt-eşik)
                      (isteğe bağlı: inv8 için ayrı fault alanı eklenebilir)

fillValve.on          oto_dolum
siteStart             site_start
fireStart             fire_start
fire1Start            fire1_start
sysOff                stop_sys   (tüm sistem kapatıldı)

MOTOR DURUMU (panelin app.js'teki gösterimi — site/fire/big için):
  sysOff (stop_sys) true  → "SİSTEM KAPATILDI"
  ilgili start kapalı      → "KAPALI"
  freq >= 1.0 Hz           → "ÇALIŞIYOR" (gerçekten dönüyor)
  aksi halde               → "BEKLEMEDE" (uyku modu / komut var ama dönmüyor)

UDP struct'ı iki tarafta da BİREBİR aynıdır (packed DEĞİL, aynı ESP32
derleyicisi). Sıra/tipler değiştirilirse paket boyutu eşleşmez.

NOT kap değerleri: tanklar[] boyutları (2500mm yükseklik, 3000mm çap)
→ tam hacim ≈ 17.7 ton. Panelin DEMO değerlerindeki 10t/5t rakamları gerçek
hesaptan farklıdır; canlı veride firmware'in gerçek hesabı gelir (yüzde
oranları tankYuzde'den birebir gelir, dolu/tonaj tutarlı olur).

3) ALAN EŞLEMESİ — DOWNSIDE (down kısmı)
================================================================================
JSON alanı            Firmware (downside_son_durum_fixed.txt)
--------------------  -------------------------------------------------------
down.p1               line_bar
down.p2               site_bar
down.p3               yan_basinc   (UDP üzerinden UPSIDE yangın basıncı)
down.pumps.inv.on     !expected_inv   (LOW=çalışıyor; web "on" artık gerçek durum)
down.pumps.yedek.on   !expected_yedek
down.pumps.kuyu.on    !expected_kuyu
down.pumps.hidrant.on !expected_hidr
down.fireTank.pct     TAHMİNİ: fireUst ? 100 : (fireAlt ? 50 : 0)
down.fireTank.s1      io.fireAlt  (VAR/YOK → panel "VAR"=true)
down.fireTank.s2      io.fireUst
down.siteTank.pct     TAHMİNİ: siteAlt ? 100 : 0
down.siteTank.s1      io.siteAlt
down.faz              io.fazOK (→ faz_stat)
down.siteSensorOK     siteSensorOK  (Madde 1: downside site sensörü sağlığı; 10sn bayatlık + V1 alt eşiği)
down.lineSensorOK     lineSensorOK  (Madde 1: downside şebeke sensörü sağlığı; 10sn bayatlık + V0 alt eşiği — yalnızca ekran)
down.alarms           alarmList[0..alarmCount-1]

NOT downside deposu yüzdesi sürekli sensörle ölçülmüyor; yalnızca alt/üst
seviye (kuru/ıslak) var. "pct" bu nedenle kaba tahmindir; panel "VAR/YOK"
çipleri (s1/s2) doğru bilgidir.

================================================================================
4) HATA / KAPALILIK DURUMLARI
================================================================================
- UPSIDE UDP paketi 5 sn içinde gelmezse: "upOnline": false ve
  site/fire/fillValve alanları sıfırlanır; down kısmı yine güncel kalır.
  Panel alarm bandı bu durumu uyarı olarak gösterebilir.
- DOWNSIDE /data hatalıysa app_live.js son iyi veriyi korur, "veri güncel
  değil" gösterir. Yeniden deneme 2 sn arayla devam eder.
